# Kanban Board 📋

My 13th assignment and my first TypeScript assignment during the Front-End Development track at Route Academy.

I built the UI and styling from scratch and used TypeScript to develop the task management functionality.

## ✨ Features

* Add, edit, and delete tasks
* Organize tasks into To Do, In Progress, and Completed
* Change task status
* Set task priority
* Add due dates
* Add task descriptions
* Form validation
* Display task counts for each status
* Show overdue and upcoming tasks
* Display relative task creation time
* Store tasks using LocalStorage
* Dynamic task rendering
* Responsive design

## 🛠️ Technologies

* HTML5
* CSS3
* TypeScript
* Bootstrap
* LocalStorage
* DOM Manipulation
